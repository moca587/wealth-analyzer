Overview

This admin console is the operations interface for the WealthAnalyzer financial planning app. It is intentionally separated from the user-facing app so that financial advisors and developers can: test calculations in isolation, edit financial constants without redeploying code, inspect & repair user profiles, and configure live market data integrations.

Deploying a Bloomberg Proxy

Bloomberg's market data is not directly accessible from a browser. You need a Bloomberg Server API (BLPAPI) license (~$25k/yr) OR Bloomberg Data License Web Services. Then deploy a small proxy that bridges browser ↔ Bloomberg.

Minimal Node.js proxy

// server.js — deploy on Render, Railway, Fly, or AWS
const express = require('express');
const cors = require('cors');
const blpapi = require('blpapi');
const app = express();
app.use(cors({ origin: 'https://your-domain.com' }));
app.use(express.json());

const session = new blpapi.Session({
  serverHost: process.env.BLP_HOST,  // your Bloomberg server
  serverPort: 8194
});

app.post('/quote', async (req, res) => {
  const { ticker } = req.body;
  // Verify auth token
  if (req.headers.authorization !== `Bearer ${process.env.AUTH_TOKEN}`)
    return res.status(401).json({ error: 'Unauthorized' });
  try {
    await session.start();
    await session.openService('//blp/refdata');
    const result = await session.request('//blp/refdata', 'ReferenceDataRequest', {
      securities: [`${ticker} US Equity`],
      fields: ['PX_LAST', 'CHG_PCT_1D', 'VOLUME']
    });
    res.json({
      price: result[0].PX_LAST,
      changePct: result[0].CHG_PCT_1D,
      volume: result[0].VOLUME,
      asOf: new Date().toISOString()
    });
  } catch (e) { res.status(500).json({ error: e.message }); }
});

app.listen(process.env.PORT || 3000);

Then in the API Keys tab, set Proxy URL to your deployed URL and Auth token to the secret token your proxy expects.

Deploying a FactSet Proxy

FactSet's WebServices use OAuth 2.0 client credentials. Similar architecture — deploy a Node.js proxy that holds your client_id and client_secret, exchanges them for a bearer token, and forwards quote requests.

// FactSet proxy snippet
const fetch = require('node-fetch');
let token = null, tokenExp = 0;

async function getToken() {
  if (token && Date.now() < tokenExp) return token;
  const r = await fetch('https://auth.factset.com/as/token.oauth2', {
    method: 'POST',
    headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
    body: `grant_type=client_credentials&client_id=${process.env.FS_ID}&client_secret=${process.env.FS_SECRET}`
  });
  const j = await r.json();
  token = j.access_token;
  tokenExp = Date.now() + (j.expires_in - 60) * 1000;
  return token;
}

app.post('/quote', async (req, res) => {
  const t = await getToken();
  const { ticker } = req.body;
  const r = await fetch(`https://api.factset.com/content/factset-prices/v1/quotes?ids=${ticker}`, {
    headers: { Authorization: `Bearer ${t}` }
  });
  const j = await r.json();
  res.json({ price: j.data[0].price, ... });
});

Going-to-Production Checklist

  • ✅ Switch to a real server-side authentication (Auth0, Cognito, or custom JWT)
  • ✅ Enable HTTPS — never run in production over HTTP
  • ✅ Move API keys server-side — frontend should only hold short-lived session tokens
  • ✅ Add rate limiting (express-rate-limit) to all proxy endpoints
  • ✅ Log all admin actions to a persistent store (Postgres, Redis, S3)
  • ✅ Add CSP headers to prevent XSS
  • ✅ Implement Content Security Policy that disallows inline scripts (refactor to external JS)
  • ✅ Enable browser caching for static assets, but never for the HTML itself
  • ✅ Set up uptime monitoring (UptimeRobot, Datadog) on all backend proxies
  • ✅ Backup user profiles regularly — they're currently stored only client-side
  • ✅ Consider GDPR/CCPA compliance if storing user data server-side

Recommended Hosting

The main app and admin can both be hosted on any static-file host: Vercel, Netlify, Cloudflare Pages, GitHub Pages, or AWS S3 + CloudFront. For backend proxies, use Render, Railway, Fly.io, or AWS Lambda.
